fork stats

Privacy-respecting pageview analytics and journeys. No cookies, no personal data — unique visitors are a daily-rotating anonymous hash, location is country-level only.

1 · Add the line

<script defer data-website="your-slug" src="https://analytics.fork.studio/beacon.js"></script>

Or in module-based projects:

import { init, page, journey } from '@fork/stats'   // bun add github:fo-rk/stats
init({ website: 'your-slug' })

2 · View the dashboard

stats.fork.studio/your-slug — supports ?days=7|30|90. Hits appear within about 30 seconds.

3 · Track journeys

<body data-journey="join">                                              <!-- page steps -->
<button data-journey="join" data-journey-step="donate-clicked">Donate</button>  <!-- click steps -->
journey('join', 'form-submitted')                                      <!-- module -->

Funnel at stats.fork.studio/your-slug/join.

Localhost traffic is ignored. Works with client-side routed sites. Email events (Resend) are collected separately in the same store.
